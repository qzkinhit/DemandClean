# License note: UniClean

Publication: UniClean: A Scalable Data Cleaning Solution for Mixed Errors based on Unified
Cleaners and Optimized Cleaning Workflow. PVLDB 18(11), 2025, pages 4117 to 4130.

No public repository with a license exists for UniClean. This directory holds the cleaning
core of UniClean (the cleaners of `SampleScrubber/`, the rule handling of `AnalyticsCache/`,
the sampling of `CoreSetSample/` and the cleaning workflow of `Clean.py` on PySpark) without
its dataset scripts, visualization and module tests, together with a wrapper for this
benchmark. It is distributed under the `LICENSE` of this repository.
