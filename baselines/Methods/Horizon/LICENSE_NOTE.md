# License note: Horizon

Publication: E. K. Rezig, M. Ouzzani, W. G. Aref, A. K. Elmagarmid, A. R. Mahmood, M. Stonebraker.
Horizon: Scalable Dependency-driven Data Cleaning. PVLDB 14(11), 2021.

The authors of Horizon link no implementation from the paper, so no upstream license applies.
This directory holds an implementation of the algorithm of the paper (FD pattern graph, pattern
quality, ordering of the FDs over the strongly connected components, pattern-preserving repair)
and its wrapper. It is distributed under the `LICENSE` of this repository.
