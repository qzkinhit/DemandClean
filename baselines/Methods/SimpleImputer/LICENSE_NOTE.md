# License note: SimpleImputer

`simpleimputer_wrapper.py` is written for this repository and falls under its `LICENSE`. It
reproduces the simple imputer of the REIN benchmark (https://github.com/mohamedyd/rein-benchmark,
EDBT 2023) with `SimpleImputer` of scikit-learn (https://github.com/scikit-learn/scikit-learn,
BSD-3-Clause), which is installed as a dependency and not bundled. The REIN repository
publishes no license file, and no file of it is included.
